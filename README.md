## IMAP vs POP3

- **POP3** descarrega els missatges a l'ordinador i, normalment, els esborra del servidor: només en queda una còpia local.
- **IMAP** deixa els missatges al servidor i sincronitza tot (llegits, carpetes, etiquetes) entre tots els dispositius.
- Per això IMAP és millor si fas servir el correu des de diversos aparells, i POP3 només si tens un sol equip.
